8/ Keeper Economy:
Anyone can run an Aeonian Keeper!
Liquidators parse gRPC Geyser streams for accounts with $HF < 1.0$. 

Liquidations return a dynamic fee reward:
$$B = \min(\text{Fixed Fee} + \text{Base Liquidated} \times 2.5\%, \text{Max Reward})$$
Keeping liquidations profitable even during micro-volatility. [9/14]
